# Documentation Campaign Workspace

This directory contains working governance and evidence artifacts for the
cross-repository Glennergy documentation campaign. These files support discovery
and review; they do not replace user-facing or technical documentation merely by
existing.

## Registers

- `CHECKPOINT_MANIFEST.md`: recoverable Git and working-tree starting state.
- `EVIDENCE_REGISTER.md`: code-backed technical findings.
- `GLOSSARY.md`: approved and candidate terminology.
- `COVERAGE_MATRIX.md`: documentation coverage and validation status.
- `OWNER_NOTES.md`: project-owner context that code may not establish.
- `CLEANUP_CANDIDATES.md`: suspected obsolete material requiring separate review.
- `SNAPSHOT_DRIFT_LOG.md`: changes to authoritative repository snapshots.

Discovery results must distinguish implemented, partial, temporary, planned,
inferred, cleanup-candidate, and unknown behavior.
